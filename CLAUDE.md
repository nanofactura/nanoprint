# CLAUDE.md

Guidance for Claude, and for every contributor, working on NanoPrint.

## What NanoPrint is

NanoPrint is an open-source desktop agent that lives in the system tray and lets web applications
print raw jobs (ESC/POS) to thermal receipt printers. It speaks the qz-tray.js wire protocol, so
existing QZ Tray clients work unchanged. Instead of QZ Tray's site-signing certificates, it asks the
user once per site and remembers the answer.

It belongs to the [Nanofactura](https://github.com/nanofactura) organization.

## Scope

- **In scope:** discovering printers, receiving print jobs over a local WebSocket, asking the user
  for permission per site, and delivering raw bytes to printers (OS print queue, USB, serial,
  TCP 9100, Bluetooth).
- **Out of scope:** invoicing, taxes, ARCA/AFIP, receipt templates, QR generation or any other
  business logic. Callers send ready-made bytes; NanoPrint never builds or inspects receipts.
- **No client SDK.** Clients use qz-tray.js-compatible libraries (for example the QZ transport of
  `web-escpos-printer`) and encoders such as `@point-of-sale/receipt-printer-encoder`. We test
  compatibility with them; we do not reimplement them.

## Maxims

### 1. Secure by default

- Listen only on loopback (`127.0.0.1`, `::1`). LAN access is opt-in, off by default, and every
  device on the LAN must be paired and approved by the user.
- Validate `Host` and `Origin` on every connection and compare origins exactly. Never trust an
  origin, path or URL sent inside a message.
- Every new site needs explicit consent in a NanoPrint window that shows its full origin.
  Decisions are stored per origin and can be revoked from the UI; revoking closes the site's open
  connections.
- Expose printing only: list printers, report status, print to printers the user has. Never expose
  files, processes, arbitrary hosts or sockets, serial or USB devices to callers.
- Never pass caller data to a shell, file path or URL. Use native APIs and argument vectors.
- Validate and size-limit every message. Rate-limit per origin.
- Run as the signed-in user, never as SYSTEM or root.
- Local TLS uses a per-install CA whose private key is destroyed right after it issues the
  localhost certificate. Never ship keys shared between installs.
- Updates are signed and verified before they are installed. Any verification failure aborts the
  update.

### 2. Compatible, not copied

- Implement the qz-tray.js wire protocol from its public documentation and from black-box
  observation of the real client talking to NanoPrint. Never copy code from QZ Tray (LGPL-2.1) or
  from any project whose license we have not approved.
- Never use the QZ Tray name, logos, the `localhost.qz.io` hostname or QZ certificates. Describe
  NanoPrint as "compatible with qz-tray.js clients".
- Defaults (ports, `wss`/`ws` behavior) match what unmodified qz-tray.js clients expect.
  Unsupported calls return a protocol error instead of being half-implemented.
- Third-party code enters only as a dependency with an approved license (`deny.toml` for Rust;
  review npm licenses before adding a package).

### 3. Small footprint

- Idle means one Rust process and a tray icon. Webview windows are created on demand and destroyed
  when closed.
- React to events instead of polling. Use async I/O.
- Justify every new dependency: size, maintenance, license. Prefer the standard library and
  well-maintained crates.

### 4. English in the repository, two languages in the UI

- Code, comments, docs, identifiers and commit messages are in English.
- Every user-facing string lives in `locales/en.json` and `locales/es.json`, shared by the web UI
  and the Rust side. No hard-coded UI text. The UI follows the system language and the user can
  override it.

### 5. Quality gates are not optional

- Rust: `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, `cargo deny check`.
  No `unsafe` outside isolated FFI modules, each block with a `// SAFETY:` comment. No `unwrap()`
  outside tests.
- Web: Prettier, ESLint (strict, type-checked), `svelte-check`, Vitest.
- Changes ship with tests. Protocol parsing gets fuzz tests.
- CI must be green before merging. GitHub Actions are pinned to commit SHAs.

## Repository map

- `src-tauri/`: the Rust application (Tauri 2). `src/lib.rs` wires plugins, the tray and the
  windows.
- `crates/protocol/`: the parser of everything a web page sends (no I/O), with property tests.
  `fuzz/` fuzzes it with cargo-fuzz.
- `src/`: Svelte 5 + Vite UI with Tailwind 4 and shadcn-svelte.
  - `src/windows/<name>/`: one entry point per window (`index.html` loads the settings window).
  - `src/lib/components/ui/`: generated by the shadcn-svelte CLI. Update it through the CLI, not by
    hand.
- `locales/`: UI strings (`en`, `es`).
- `assets/brand/`: logo and isologo SVG masters. `npm run icons` regenerates every raster icon
  (tray and app icons in `src-tauri/icons/`); never edit the generated PNGs by hand.
- `docs/architecture.md`: design decisions and roadmap.
- `docs/protocol.md`: the wire protocol. `docs/integration.md`: guide for web developers
  (libraries, permission, HTTPS, site name and logo, limits). Update them with any change a page
  can observe.
- `docs/threat-model.md`: what NanoPrint protects and how. Update it with any change to the
  print server, permissions, storage or releases.
- `docs/releasing.md`: release process, code signing and update key custody.

## Commands

```sh
npm install              # also installs the Tauri CLI
npm run tauri dev        # run the app in development
npm run build            # build the web UI into dist/ (needed before any cargo command)
npm run format           # Prettier
npm run lint             # ESLint
npm run check            # svelte-check + tsc
npm test                 # Vitest
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace   # includes a compatibility test that runs qz-tray.js (needs npm install)
cargo deny check         # requires cargo-deny
npm run notices          # third-party license notices; requires cargo-about
cargo +nightly fuzz run parse   # fuzz the protocol parser; requires cargo-fuzz (see fuzz/)
```

## Conventions

- [Conventional Commits](https://www.conventionalcommits.org/). Sign off every commit
  (`git commit -s`, Developer Certificate of Origin).
- `Cargo.lock` and `package-lock.json` are committed.
- The version lives only in the root `Cargo.toml` (`[workspace.package] version`, SemVer). Never
  add a `version` to `tauri.conf.json` or `package.json`; read it at runtime instead.
- New Tauri command: list it in `src-tauri/build.rs` and grant it only in the capability of the
  window that uses it (`src-tauri/capabilities/`).
- New shadcn-svelte component: `npx shadcn-svelte@latest add <name>`, then `npm run format`.
- License: GPL-3.0-only (`LICENSE`). Every dependency must be GPL-3.0 compatible: `deny.toml`
  and `about.toml` list the accepted Rust licenses, `scripts/third-party-notices.mjs` the npm
  ones.
- npm: packages bundled into the app go in `dependencies`, tools in `devDependencies`; the license
  notices depend on that split. Install scripts stay disabled (`.npmrc`).
- Log at `info` what helps diagnose a user's problem; never log printed content or secrets.
- Mention QZ Tray only to describe compatibility, never in product names or branding. Every
  document that names QZ Tray or qz-tray.js carries the non-affiliation notice (code comments
  excepted):

  > QZ Tray and qz-tray.js are products of QZ Industries, LLC; QZ Tray is its trademark. NanoPrint is an independent project, not affiliated with or endorsed by QZ Industries, and mentions them only to describe compatibility.
