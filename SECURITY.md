# Security policy

NanoPrint runs on users' machines and accepts connections from web pages, so we treat security
reports as top priority.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/nanofactura/nanoprint/security/advisories/new).
Do not open public issues for security problems. If you cannot use GitHub, write to
[hola@nanofactura.com](mailto:hola@nanofactura.com) with "Security" in the subject.

Please include the affected version, your operating system, steps to reproduce and the impact you
expect. We aim to acknowledge reports within 3 business days and to agree on a disclosure date
with you.

## Supported versions

NanoPrint is in early development. Only the latest release receives security fixes.

## Scope

In scope: anything that lets a web page, a LAN device or another local user print without the
user's consent, read data, control the machine, bypass the permission prompt, or tamper with
updates.
